Purpose
-------
Provide a stable, provider-independent data contract for explicit transfers
between Wonderlog, Anna's Diary, Notes, TrailPath and future ecosystem apps.

The bridge is NOT:
- a shared database;
- a background sync of all user data;
- a replacement for each app's domain model;
- a Supabase-specific protocol.

Canonical ownership
-------------------
Each entity remains canonical in its owning app.

COPY:
- destination materializes an independent local entity;
- the source remains owner of the original entity;
- provenance of the source is preserved;
- future source revisions are NOT applied automatically.

LINK:
- destination stores a reference/projection to the canonical source;
- canonical content remains owned by the source app;
- a canonical deep link is mandatory;
- LINK does not imply automatic cloud sync.

Identity and idempotency
------------------------
bridgeId is stable for one canonical owner/entity:

  ecosystem:v1:<ownerApp>:<ownerEntityType>:<ownerEntityId>

revision identifies the source revision represented by the envelope.

idempotencyKey is:

  <bridgeId>:<revision>:<copy|link>

Therefore:
- COPY and LINK are distinct deliveries;
- sending the same mode/revision twice is idempotent;
- a new revision creates a new idempotent delivery while keeping bridgeId
  stable.

Legacy compatibility:
- historical pre-E1 schema-v8 keys are recognized as COPY deliveries only;
- a matching legacy COPY key MUST NOT suppress a LINK delivery;
- concurrent duplicate insertion must remain atomic/idempotent.

Provenance
----------
Every envelope carries:
- ownerApp;
- ownerEntityType;
- ownerEntityId;
- ownerRevision;
- canonicalDeepLink when available;
- optional parentBridgeId for derived/re-shared entities.

A receiving app must not silently replace provenance with its own identity.

Fallback
--------
Every transferable envelope provides at least one fallback:
- plainText;
- sourceDeepLink;
- webUrl.

The current local transport uses a portable clipboard fallback when the target
app cannot be opened.

Media
-----
Private local URIs MUST NEVER cross the bridge.

Forbidden wire values include:
- file://
- content://
- media://
- /data/...
- /private/...

The envelope carries safe media metadata plus an explicit handoff descriptor.

Supported handoff kinds:
- omitted: metadata is transferred, binary handoff is intentionally absent;
- shareToken: a transport-specific expiring token;
- cloudObject: a provider-specific safe locator.

The current Wonderlog v1 producer uses "omitted" for media binaries until a
separate explicit binary handoff transport is certified.

Local transport v1
------------------
Portable package:
- transportVersion = 1;
- targetApp;
- createdAtUtc;
- EcosystemEnvelope v1.

Deep-link target convention:

  <targetScheme>://ecosystem/import?payload=<base64url-package>

Anna's Diary target scheme reserved by this contract:

  annasdiary://ecosystem/import

Portable clipboard fallback prefix:

  ECOSYSTEM_BRIDGE_V1:

The destination must validate schema, capability, privacy scope and
idempotency before materialization.

Malformed/untrusted package fields must fail closed and be normalized to a
stable parsing error surface rather than leaking arbitrary cast/enum/date
exceptions.

Cloud transport
---------------
Cloud is an OPTIONAL second transport.

The data contract does not depend on Supabase, Firebase or another backend.
A cloud adapter may transport the same envelope, but provider-specific queues,
retry, tombstones, cursors, auth and conflict resolution remain outside this
contract.

Privacy
-------
Cross-app transport requires:

  privacyScope = explicitShare

Private envelopes fail closed.

Destination behavior
--------------------
The destination:
1. validates the contract;
2. checks target capability;
3. checks idempotency;
4. shows/uses the explicit COPY or LINK semantic;
5. materializes only after the destination-side workflow allows it;
6. preserves provenance;
7. never reads the source app's private database directly.
