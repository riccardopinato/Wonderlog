Wonderlog producer guarantees
-----------------------------
The frozen Wonderlog baseline guarantees:

1. Shared Ecosystem Core v1 envelope validation before durable persistence.
2. Stable bridgeId for the same canonical source entity.
3. Idempotency identity:
     <bridgeId>:<revision>:<copy|link>
4. COPY and LINK remain distinct durable deliveries.
5. Same-mode duplicate deliveries are idempotent.
6. Concurrent outbox enqueue is atomic and returns the canonical stored row.
7. Concurrent inbox duplicate reception does not create duplicate rows.
8. Pre-E1 schema-v8 legacy keys map to COPY only.
9. A legacy COPY row never suppresses LINK for the same source/revision.
10. Malformed transportVersion / targetApp / createdAtUtc / envelope shapes
    fail as FormatException.
11. Contract-invalid packages fail closed.
12. Private source-local media URIs are never transferred.
13. Target deep-link transport and portable clipboard fallback are supported.
14. Target-unavailable deliveries remain durable/retryable in the outbox.

Anna consumer requirements
--------------------------
1. Register:
     annasdiary://ecosystem/import?payload=<base64url-package>
2. Decode EcosystemTransferPackage v1.
3. Require targetApp == annas_diary.
4. Validate EcosystemEnvelope v1 before any materialization.
5. Deduplicate by:

6. Preserve provenance.
7. Keep COPY and LINK semantically distinct.
8. Never read Wonderlog's private DB.
9. Never accept source-local media URI as transferable media.
10. Show/execute Anna-side destination workflow before creating Anna data.
11. Run the same Golden contract vectors used by Wonderlog.
12. Verify malformed/untrusted input fails closed.
13. Verify duplicate/concurrent delivery does not duplicate Anna entities.
