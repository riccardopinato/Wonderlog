Itinerario di viaggio, prenotazioni/mezzi, budget e packing; integrare nei proprietari viaggi/ricordi esistenti, non importare database Notion. L'export contiene 15 file Markdown, 6 CSV e 4 immagini; sono osservabili quattro tappe, quattro elementi budget e tre voci packing. Non è prova di sincronizzazione, formule, routing, UX o funzionamento dei pulsanti.
